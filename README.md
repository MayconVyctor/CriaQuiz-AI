# CriaQuiz-AI
CriaQuiz — Plataforma de geração de quizzes com IA  

-Aplicação web fullstack que permite ao usuário gerar quizzes personalizados por tema ou a partir de materiais próprios (PDF/texto), utilizando inteligência artificial para criação das perguntas.  Tecnologias: Java 21 · Spring Boot 3 · PostgreSQL · React · Docker · GeminiAPI

-Focada em ajudar estudantes
